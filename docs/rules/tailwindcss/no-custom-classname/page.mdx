# `@elsikora/tailwindcss/no-custom-classname`

<Callout type="info" emoji="🧭">
	**Disabled.** ElsiKora includes this rule as an intentional disabled override in at least one preset scenario.
</Callout>

## Rule Overview

Detects classnames which do not belong to Tailwind CSS.

This page describes the rule in general first, then shows the exact ElsiKora preset configuration separately.

## Rule Metadata

| Property           | Value        |
| ------------------ | ------------ |
| Type               | `suggestion` |
| Fixable            | ❌ No        |
| Has suggestions    | ✅ Yes       |
| Deprecated         | ❌ No        |
| ESLint recommended | `unknown`    |

## All Supported Options

The rule exposes the following ESLint option schema:

```json filename="options-schema.json" copy
[
	{
		"type": "object",
		"properties": {
			"whitelist": {
				"description": "List of classnames to ignore (whitelist). Exact match or regular expression.",
				"type": "array",
				"items": {
					"type": "string",
					"minLength": 0
				},
				"uniqueItems": true
			}
		},
		"additionalProperties": false
	}
]
```

Upstream default options:

```json filename="default-options.json" copy
[
	{
		"whitelist": []
	}
]
```
