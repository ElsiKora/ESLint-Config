# `@elsikora/javascript/preserve-caught-error`

<Callout type="error" emoji="🚨">
	**Error.** ElsiKora reports this rule as an error in at least one preset scenario.
</Callout>

## Rule Overview

Disallow losing originally caught error when re-throwing custom errors.

This page describes the rule in general first, then shows the exact ElsiKora preset configuration separately.

## Examples

<Tabs items={["❌ Avoid", "✅ Prefer"]}>
  <Tabs.Tab>

```js filename="bad-example.js" copy
try {
	await saveUser(user);
} catch (error) {
	throw new Error("Unable to save user");
}
```

  </Tabs.Tab>
  <Tabs.Tab>

```js filename="good-example.js" copy
try {
	await saveUser(user);
} catch (error) {
	throw new Error("Unable to save user", { cause: error });
}
```

  </Tabs.Tab>
</Tabs>
