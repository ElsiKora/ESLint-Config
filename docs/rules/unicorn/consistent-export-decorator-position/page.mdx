# `@elsikora/unicorn/consistent-export-decorator-position`

<Callout type="error" emoji="🚨">
	**Error.** ElsiKora reports this rule as an error in at least one preset scenario.
</Callout>

## Rule Overview

Enforce consistent decorator position on exported classes.

This page describes the rule in general first, then shows the exact ElsiKora preset configuration separately.

## Rule Metadata

| Property           | Value           |
| ------------------ | --------------- |
| Type               | `suggestion`    |
| Fixable            | ✅ Yes          |
| Has suggestions    | ❌ No           |
| Deprecated         | ❌ No           |
| ESLint recommended | `unopinionated` |

## All Supported Options

The rule exposes the following ESLint option schema:

```json filename="options-schema.json" copy
[
	{
		"enum": ["above", "before", "after"],
		"description": "Decorator position relative to the export declaration."
	}
]
```

No upstream default options are exposed in the rule metadata.
